	- The prompt (user part of the conversation) is masked; only report tokens are used for training
	- In evaluation mode, the tokenized report is returned (without conversation context)
- Checkpoints are saved every 500 steps in `safetensors` format
- Hessian.AI storage space issue – workaround:
	- Persistent workspace storage becomes visible by adding the following to the configuration:
		```yaml
		- container_path: /pfss/mlde/workspaces/mlde_wsp_RWTH_MedReport
		  host_path: /pfss/mlde/workspaces/mlde_wsp_RWTH_MedReport
		  propagation: rprivate
		  read_only: false
		```
