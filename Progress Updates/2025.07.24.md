## 2. Technical Details
- **Multihead Attention in Reward Model Training:**
  - **Query**: What to look for (radiology report features)  
  - **Key**: What each token represents (image features)  
  - **Value**: What is returned (image features)

- **Image Resolution:**
  - Tradeoff: interpretability vs. processing time
  - MIMIC-CXR-JPG resolution: ~2500 × 3056 px (~7.6M pixels, 19,900 tokens)
  - Qwen2.5-VL supports a max token sequence of ~16,000 tokens per image
    - Recommended pixel range:
      - `min_pixels = 256 * 28 * 28` (~0.2M)
      - `max_pixels = 1280 * 28 * 28` (~1.0M)  
      [Reference](https://github.com/QwenLM/Qwen2.5-VL?tab=readme-ov-file)
    - Implication: resizing compresses images significantly, potentially losing diagnostic detail
  - Plan: resize images to longest side of **1024** and **2048**, keeping aspect ratio  
    → this will create two datasets for performance comparison

- **Padding:**
  - Batches require uniform input sizes
  - Since `max_seq_length` is unknown per batch, I will use a custom `collate_fn` in the `DataLoader` for dynamic padding
