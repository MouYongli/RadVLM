# 26.01.2026

## 1. Progress Update
- Tuned hyperparameters across multiple training configurations.
- Experimented with DPO training using `trl`’s `DPOTrainer`.
	- The official `DPOTrainer` documentation states that **VLM support is exclusive to Idefics2** and does not extend to other VLMs.
	- While `trl==0.12.0` introduces support for all VLMs, it requires `transformers>=4.46.0`, which is **incompatible with DeepSeek-VL2** (requires `transformers==4.38.0`).
- Justification for continuing to use **DeepSeek-VL2** as the base model:
	- DeepSeek-VL2 provides a **strong, open, and scalable vision–language foundation**. Its architecture and pretraining strategy make it particularly well-suited for domain adaptation to radiology report generation on **MIMIC-CXR**, enabling both competitive performance and meaningful scientific analysis.
