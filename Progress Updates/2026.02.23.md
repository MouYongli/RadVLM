## 2. Technical Details

### Training on Vision Encoder

- Both base models (DeepSeek and MedGemma) contain **26 vision blocks**
- Added the last 6 vision blocks + attention modules to LoRA for fine-tuning
- **DeepSeek**
	- Added projection modules to LoRA
	- Full fine-tuning not possible due to OOM errors
- **MedGemma**
	- Unfroze projection modules for full fine-tuning
- Custom optimizer:
	- 8-bit optimizer
	- Higher learning rate for projector: **3e-4**
	- Language model learning rate: **1e-4**

**Interpretation (MedGemma):**

- LoRA fine-tuning dramatically improves performance:
	- Perplexity drops from **71.8 → 2.65**
	- RadGraph-F1 (complete) improves from **0.175 → 0.199**
- Adding vision blocks alone does not significantly improve RadGraph performance.
- However, **adding projection modules (vision-proj)** yields the **best RadGraph scores**:
	- RadGraph-F1 (simple): **0.2866**
	- RadGraph-F1 (complete): **0.2085**
- Lexical metrics (BLEU) slightly decrease while RadGraph improves.
	- This suggests improved **clinical structural correctness**, even if surface n-gram overlap drops.
- Increasing LoRA rank to 64 does not help and slightly degrades RadGraph performance.

## DPO Training

Challenges:
- `trl`’s `DPOTrainer` assumes a fixed number of images per sample.
- MIMIC-CXR contains 1–4 images per study.
- DeepSeek is incompatible with `DPOTrainer` due to transformer version conflicts.
- Implemented a custom DPO training script.

**Interpretation (DPO):**

- DPO improves **RadGraph-F1 (simple)** from 0.276 → **0.285**.
- However, **RadGraph-F1 (complete) slightly decreases** (0.199 → 0.194).
- Cross-entropy loss and perplexity slightly increase, which is expected since DPO optimizes preference alignment rather than likelihood.
- Lexical metrics (BLEU-4, ROUGE-2) decrease slightly.

**Conclusion:**  
RadGraph-based DPO improves entity-level correctness (simple F1), but may weaken full structural consistency (complete F1).  
The small dataset size (25 training samples) likely limits the effectiveness of preference learning.
