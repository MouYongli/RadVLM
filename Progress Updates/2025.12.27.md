## 2. Technical Details
- **Training framework**
  - Selected **DeepSpeed + Accelerate** for pre-training (language model only)
  - Chosen for its lower configuration overhead compared to alternatives such as PyTorch Lightning

- **Parameter-efficient fine-tuning**
  - Adopted **LoRA (Low-Rank Adaptation)**
    - Parameter-efficient: trains only a small subset of parameters
    - Faster training and reduced memory footprint
    - Trade-off: potential information loss due to reduced parameter capacity
	- Example Code:
		```python
		
        lora_config = LoraConfig(
            task_type=TaskType.CAUSAL_LM,
            r=16,
            lora_alpha=32,
            lora_dropout=0.05,
            bias="none",
            target_modules=[
                "q_proj",
                "k_proj", 
                "v_proj",
                "o_proj",
                "gate_proj",
                "up_proj",
                "down_proj"
            ],
            inference_mode=False,
        )
		```
		- Parameter explanation:
			- `task_type`: Determines which task is trained for
			- `r`: Rank of the low-rank update matrices, the higher the more parameters
			- `lora_alpha`: Controls how strongly LoRA influences the base model
			- `lora_dropout`: Regularizes the adaptation matrices using dropout on LoRA
			- `bias`: Controls whether bias terms are trained
